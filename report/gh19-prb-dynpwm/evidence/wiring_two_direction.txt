THE CODE-WIRING (④) TWO-DIRECTION ACCEPTANCE, both directions now RUN end-to-end.

Question being answered. The wiring derives a code suffix from the criteria KEY NAME and maps it at the
two bucket-recording sites, so that the criteria -- not the tool -- owns the printed code vocabulary.
"Output unchanged" is necessary and NOT sufficient: a gate that builds the map and never consults it
prints exactly the same bytes. So identity alone cannot tell a live read from a dead one.
