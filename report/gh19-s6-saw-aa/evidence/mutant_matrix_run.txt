1. The arms run concurrently, so the ORDER of the blocks below is nondeterministic.
   Two independent full runs were compared as multisets of lines: they are identical
   except for the final `EXIT=0` line, which the first run did not capture because of
   how it was launched. Compare content, not line order.

2. `phase-drift` spends three lines on its `ANALYZE-FAILED` block whose cell rows are
   the tail of the analyzer's own stdout. Those rows are the instrument reporting the
   cells it refused; they are not a measurement of the DSP. The same applies to the
   other two license-refused arms.

The `EXIT=0` line is present because the run was launched as
`sh -c '... ; echo "EXIT=$?"'`. It is a measurement, not a transcription: the
sentence used for the first run came from the driver's own PASS branch and the exit
code was not captured at all, so it was re-run to obtain it.
