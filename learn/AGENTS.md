# 教程维护约定

本目录是 Lunar 24 的中文教程，随仓库提交。`.build/`（中间文件）和 `source/node_modules/` 不提交，已写在 `learn/.gitignore`。改动走分支和 PR，由作者合并。

先读 README.md。内容只改 `source/content.py`，版式只改 `source/deck.mjs`，不要手改 `.build/` 或 `output/` 里的生成物。当前交付版本是 `output/v4`；大改时用新的版本号，确认后删掉旧版本。

受众是 16–17 岁、喜欢电子音乐的中学生，手里只有装好的 Lunar 24 和这份教程：读者材料里不出现仓库、源码、文件路径或开发文档；这些依据只写进 README 的核对表。先讲听到什么，再讲机制和操作；每页一个可执行的练习和恢复方法。缩写第一次出现要给中文全称；合成器术语交给“嗡嗡词典”解释。

沿用面板配色、Noto Sans / Noto Sans SC / Saira 字体和红色小精灵。面板图由 App 的共用绘制代码生成，示例状态要说明，不冒称真实设备连接或人工试听。产品行为以当前源码为准，不把硬件手册的行为直接套到软件。

导出后 `deck.mjs` 的 CHECK 必须为零，并逐页查看受影响的 PNG；结构检查不能替代视觉检查。音频无需无故重新生成。
