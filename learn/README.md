# Lunar 24 声音实验室 · 维护说明

这份说明只给教程作者看，读者材料里不出现仓库、代码或文档路径。

读者入口：`index.html`（跳到 `output/v4/index.html`）。交付物在 `output/v4/`：61 页 PNG、可打印 PDF、阅读页（逐页图片 + 8 段试听 + “再深入一点” + 全部 84 条“嗡嗡词典”）。

## 目录

- `source/content.py`：**唯一的内容源**。每页的文字、版式、面板裁切（`FIGS`）、红框标注、“嗡嗡词典”（`TERMS`）、缩写表、卡带中文名都在这里。
- `source/deck.mjs`：版式与样式，用 Chrome 输出 PNG 和 PDF，并自动检查文字溢出、出界、标题换行。
- `source/preview.py`：阅读页。
- `source/build-preview-tool.py`：把 App 的 `tools/panel_preview.cpp` 复制一份加上教程用的示例状态，编译成 `.build/tutorial_preview`，并导出控件坐标 `.build/widgets.json`。不改 App 源码。
- `source/render-panels.mjs`：用上面的工具渲染 13 种面板状态的 3 倍母图（`.build/masters/`），文字用 App 内置的同款 Noto Sans。
- `source/prepare-assets.mjs`：按 `FIGS` 从母图裁出 `assets/figs/*.jpg`，并从封面插画抠出小精灵 `assets/art/critter-*.png`。
- `source/render-audio.py`：用 `build/lunar24_render` 生成 8 段试听（命令和峰值记录在 `assets/audio/manifest.json`）。
- `assets/fonts/`：Noto Sans、Noto Sans SC、Saira（均为 SIL OFL，许可见 `OFL.txt`）。和面板同一套字体：面板文字是 Noto Sans，Logo 是 Saira。
- `.build/`：中间文件，可随时重建。

## 准备环境（第一次）

需要：Python 3、Node（含 npm）、Google Chrome、C++ 编译器（Xcode 命令行工具）。重做试听还需要先按仓库根目录 README 编译出 `build/lunar24_render`。

```sh
cd learn/source && npm install && cd ../..        # 装 playwright-core（借用本机 Chrome）和 sharp
```

## 重新生成

在仓库根目录运行。按改动的范围，从对应的那一步开始，往下全部跑完：

```sh
python3 learn/source/build-preview-tool.py         # 1. App 面板改了：重建面板工具和控件坐标
node learn/source/render-panels.mjs                # 2.             重渲母图
python3 learn/source/content.py                    # 3. 改了 content.py（任何文字、标注、裁切）：从这里开始
node learn/source/prepare-assets.mjs               #    改了 FIGS 裁切框才需要
LEARN_REV=v4 node learn/source/deck.mjs            # 4. 只改了 deck.mjs 版式：从这里开始。出 PNG + PDF
python3 learn/source/preview.py v4                 # 5. 阅读页（同时更新 learn/index.html 的跳转）
python3 learn/source/render-audio.py               #    只在要重做试听时运行
```

试排几页：`LEARN_ONLY=07,12 LEARN_REV=v4 node learn/source/deck.mjs`（不出 PDF）。大改时把两处 `v4` 换成新版本号，确认满意后删掉旧版本目录。

重渲母图（第 2 步）后，内容没变的图片也可能出现肉眼看不出的字节差异。提交前用 `git checkout -- <文件>` 还原这些图，再重跑第 4、5 步，让提交里只有真正改过的页。

`deck.mjs` 打出的 `CHECK` 行必须为零，之后仍要逐页看 PNG：
- `overflows` / `spills out of the body`：文字太长，删短一点，或把这页的 `figw`（图占的宽度比例，默认 0.5）调小。
- `title wraps`：标题超过一行，缩短标题。
- `outside the safe area` / `tag touches the title`：标注太靠边，换个位置或去掉一个标注。

## 常见维护任务（都在 `source/content.py` 里改）

- **改文字**：找到对应的 `page(...)`。`blocks` 固定两组小标题 + 要点，每组 2–3 条，每条一句话；`try_` 是底部“动手试试”，一句话；`more` 只出现在阅读页的“再深入一点”，可以写长一点。
- **加术语**：在 `TERMS` 里加一条 `键: (名称, 英文全称, 中文名, 解释)`，再写进对应页的 `terms=[...]`。每页最多 2 个，超过会报错。阅读页的完整词典会自动收录。
- **给面板图加标注**：`fig('图名', mk('控件 id', label='名字'))` 是黑色编号加图例；`mk('控件 id', n='1')` 是红色跳线端点；`mk([多个 id], label=...)` 框住一组；加 `split=True` 时同一编号分别框住每个控件。控件 id 在 `.build/widgets.json` 里查（如 `vco_a.pwm_in`）；没有 id 的控件用 `deck.mjs` 开头 `ALIAS` 里的别名（如 `drone_key.1`、`joystick.stick`）。
- **换一张面板图 / 新的裁切**：在 `FIGS` 里加 `名字: (面板状态, x, y, 宽, 高)`，坐标单位是面板单位（整块面板 2400 × 1552）。面板状态是 `render-panels.mjs` 里 `VARIANTS` 的名字（`panel`、`play`、`midi` 等），需要新状态就在那里加一个，参数参考 `.build/tutorial_preview.cpp` 开头的说明。
- **加页 / 调顺序**：`page(...)` 的先后就是页码，页码自动重排。版式 `layout` 可选：`split`（图左文右）、`wide`（图上文下）、`mission`（插画练习页）、`flow`（流程图，图在 `deck.mjs` 的 `DIAGRAMS`）以及几种专用页。
- **加试听**：在 `render-audio.py` 的 `cases` 里加一段 `lunar24_render` 参数，运行后在对应页写 `audio='编号'`。

## 交给学生

PDF 是独立文件，可以单独发。阅读页（带试听和完整词典）要整个 `learn/` 文件夹一起给，并让学生打开 `index.html`：它通过相对路径引用 `assets/` 里的音频、图片和字体。`source/`、`.build/`、`README.md`、`AGENTS.md` 是维护用的，给学生时可以删掉。

## 约定

- 配色取自面板：奶油底 `#E9E0D2`、墨黑 `#0C0A0A`、红 `#CB2026`、青 `#005E7A`、绿 `#005E3B`、橙（加深）`#A14E16`。章节色：Drone / 外部 = 青，VCO / 键盘 = 绿，混音 / 效果 = 橙，其余 = 红。
- 每页一个“动手试试”，最多两个术语交给右下角的“嗡嗡词典”；术语第一次出现时解释，全集在阅读页末尾。缩写第一次出现时写出中文全称，第 5 页是缩写总表。
- 面板图标注：红色 ①② 是跳线的两端，黑色编号对应图下的图例；同一页有跳线时，黑色图例改用 A、B、C。标注用控件的 registry id，面板改版后坐标自动跟着走。
- 文字以 App 当前行为为准，不把硬件手册的说法直接套过来；示例 MIDI 设备是渲染示例，不是真实连接。
- 制作说明不进读者材料，只记在这里：面板图由 App 的绘制代码离线渲染（Drone 键按开机状态画成全暗），不是运行中的截屏；8 段试听由 `lunar24_render` 离线生成，48 kHz / 16-bit，App 的 REC 录的是 24-bit。
- 随仓库提交：`source/`、`assets/`、`output/` 当前版本、`index.html` 和两份说明；`.build/` 与 `source/node_modules/` 由 `learn/.gitignore` 排除，可随时重建。
