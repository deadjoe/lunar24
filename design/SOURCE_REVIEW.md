# 音源设计审查与听感记录（2026-10-08）

这次没有改代码。本文记下审查时的要求、音源算法的判断、实施代理核对之后的修正、三组可以重做的面板操作，以及听完以后的结论。以后调音时先看第 7 节，要重听就按第 6 节做。

## 1. 审查要求

业主对这次审查提了两点，审查按这两点进行，不是按“代码写得干不干净”，也不是按“有没有复刻未知电路”。

1. 音源是整台乐器的基础。六个 drone、两只可演奏振荡器、噪声，设计和实现要站得住。后面的混音、滤波、失真和效果都建立在音源上。业主第一次做这个领域，振荡器和算法需要借助已有的合成器实践来把关，不能只对照手册里的功能名称。
2. Lunar 24 不是 Solar 42N 的克隆。买不到那台硬件，手册也不公开内部电路。借鉴的是操作界面和功能分类。技术实现是一台软件的 ambient / drone 合成器。没有原理图时去做电路仿真，不会更正确。

因此要回答的是：现在用的算法，是不是这个领域里已经成熟的做法；有没有业主还不知道、但以后调音用得上的做法。听感由业主裁决。下面凡是“更好听”而还没听过的，都只算候选，不算缺陷。

## 2. 两套判断标准

审查里出现过两套尺子，结论不同时要先分清用的是哪一套。

- **软件 drone 的成熟做法。** 看同类乐器和公开的算法里，这种声音通常怎么做。过零调频、施密特电容上的指数斜坡、噪声的频谱，属于这一套。
- **仓库里已经写下来的决定。** `design/ARCHITECTURE.md`、`design/DECISIONS.md`、`design/STATUS.md` 里写明的行为、暂定模型和项目边界。手册点名的芯片、面板上有的功能、听感调过的选择，属于这一套。

两套尺子冲突时，以已经写下来的决定为准，直到业主改写对应的句子。已经写进文档，也不等于耳朵否决过另一种声音。闪光混响的“更多读头”是测过并且退回的。过零、三角波、白噪声、drone 直线包络是暂定模型或项目边界，没有一段录音说另一种听起来更差。

## 3. 已经站得住、不必因为“还有更高级的合成法”而重写的部分

这些是这次审查里认为用对了的，以后调音不要先拆掉它们。

**四个经典声部（1 / 2 / 4 / 5）。** 每个声部五只自由运行的锯齿，音程比 1 : 1.5 : 2 : 3 : 4，再加大约 ±1.2% 的固定误差。慢漂移是会慢慢回到中心的随机游走（Ornstein–Uhlenbeck），大约 ±3 到 8 音分、几十秒的尺度，每个周期还有一点阈值抖动。包络不重置相位，拍频可以一直连着。这是管风琴混合音栓和模拟 drone 的标准堆法，比单只“超锯齿”适合这台琴。波形是电容充电那种先快后慢的斜坡，放电沿用两点 polyBLEP，再加轻度软饱和。音高在 55–300 Hz 一带时，这种抗混叠够用；可演奏振荡器上已经测过，两点 polyBLEP 在高音会留下大约 −40 dB 的混叠，所以那边换成了更长的核。经典声部不必为了同一理由再换。

**可演奏振荡器 VCO A / B 的稳态波形。** 相位累加器。锯齿和方波用窗函数 BLEP（单侧 8 点，核大约 16 个采样），三角波用 BLAMP。这是 Välimäki 等人发表、虚拟模拟合成器也在用的抗混叠。稳态波形上实测大约 −70 / −85 dB。不做电路级的 AS3340 仿真：没有这台琴的原理图，行为模型是专业做法。

**滤波器。** 零延迟状态变量滤波器，积分器会饱和，共振开大能自己叫，12 dB/倍频程。这个陡度留得住互相拍的泛音。24 dB 的梯级滤波会把那些泛音吃掉。它听起来不是一台真的 Polivoks，作为这台软件琴的滤波器，这个选择比去猜未知电路合适。

**失真和混响。** 失真是 tanh 加一阶 ADAA（用波形的解析积分减轻数字削波的混叠）。混响是 16 条调制过的反馈延迟网络。采样保持用白噪声是对的，因为每次采样要一个互不相关的新值。

**不要换成另一类合成法来“升级”这些音源。** 波形表、粒子合成、模态共振（虚的弦或板）是另一台乐器。折叠波能给三角波加上新谐波，和这台琴同一家族，但面板上没有这个功能，留作以后的音色，不是现在的缺陷。环形调制允许音量乘到负数，从而出现新的和频与差频。声部 3/6 现在的 AM 开满时是在静音和两倍音量之间跳，不产生新音高。那是另一种效果，不是 AM 做坏了。

## 4. 三处值得先听清楚的差别

### 4.1 过零调频

线性调频把调制电压加进频率。`CV × cv amt` 小于或等于 −1 时，现在的做法把频率停在 0，振荡器停住，相位不再往前走，也不倒着走。可演奏振荡器的产品路径是这个公式（`vco.h` 的 `frequencyHz()`）。默认接线是 VCO A 的原始波形进 VCO B 的 **cv**，**cv amt** 默认开满，**lin / exp** 默认是线性。

过零调频不把频率停在 0。电压再往负走，振荡器倒着跑，波形像在时间上折返。负频率就是时间反转。Buchla、Make Noise DPO、Doepfer A-110-4 这条线上用它做出深的、会“撕开”的模拟调频。普通 AS3340 的线性调频输入会把频率推到停振，不会倒着走。过零振荡器是另一类电路。`ARCHITECTURE.md` 第 4.3 节已经写了：这条面板通路不做过零，手册没说硬件是否支持。所以对 VCO A/B，过零不是漏实现。它是一条已经写下来的决定。手册点名 AS3340，只说明“不过零”和手册不冲突，不能证明这台琴的内部一定没有额外电路。

经典声部的互调频深度上限是 0.9，频率最慢还剩原来的大约一成，正常拧 **VOLT** 不会走到停振。那里过半以后的颗粒是音频速率的互相调制，不是过零缺失。声部 3/6 的调频是指数的，方波让音高在两个音之间跳，最深大约 ±3 个八度。指数永远乘一个正数，不存在过零问题。

代码里有一组没有被产品调用的加性调频接口。相位在负向深度超过当前音高时可以倒走，三角波的抗混叠用了步长绝对值，所以计算不会散。锯齿和方波的长 BLEP 没有按过零调频设计和测量。以后若要做，不必从零搭相位，但不能把这个接口当成已经做好的过零算法。

### 4.2 声部 3/6 的直线三角波

RC 加施密特触发器时，电容电压是两段指数充放电，输出脚才是方波。直线三角波需要恒流积分器。直线三角波只有奇次谐波，而且掉得快，听感空、柔，接近笛声。方波同样偏空，但更硬，带鼻音。锯齿亮，发嗡。指数斜坡会落在三角波和锯齿之间：还是圆的，但更亮、多一点嗡。

Lunar 24 用对称直线三角波当作声部 3/6 的音调，方波只拿去当调制（`ARCHITECTURE.md` 3.1，标明是软件波形模型，不是实机测量）。若硬件上听的是输出脚，指数斜坡和直线三角就都不是那个节点，应是方波。手册没说听的是哪一个节点。这个波形不在面板上切换，所以听不出“换过去会不会更好”。

### 4.3 白噪声和采样率

**NOISE** 放出来的是每采样一个均匀随机数的白噪声：各频率一样响，听感是亮的嘶声。同一振幅铺到更高的奈奎斯特频率上，可听的那一段就变轻。48 kHz 改到 96 kHz，可听带大约少 3 分贝，听起来是轻轻变弱。代码注释和测试里已经测量并明确先不改（`drone_noise.h`）。采样保持继续用这份白噪声。把可听噪声改成响度不随采样率变化，和把它改成更闷的粉红噪声，是两件事。粉红噪声是低频更重的另一种音色。

## 5. 实施代理核对之后收回或改口的建议

实施代理把审查里可核对的实现描述对照了代码，事实层成立，措辞有几处精度问题，不影响方向。审查初稿把下面几条说成了“还没人想过的缺口”。核对文档之后改口如下。

| 初稿里的建议 | 核对后的位置 |
|---|---|
| 过零调频是最大的一块，含默认的 A 调制 B | VCO 的不过零已写在 `ARCHITECTURE.md` 4.3，且与 AS3340 的常规线性调频一致。经典声部的过零仍是创作选择，因为没有芯片依据，而且 0.9 的深度上限让正常 **VOLT** 到不了停振 |
| 可听噪声改成粉红或固定带宽 | 采样率问题已测量、已暂缓。粉红是改音色。固定带宽的白噪声才对得上“响度不跟着采样率走” |
| 闪光混响改用更多读头，或两只移调器送进混响 | 更多读头已经试过，纯音上出现大约 −30 dB 的、随音高移动的陷波，所以保留双读头（`DECISIONS.md`）。Cathedral Shimmer 已经是高八度和低八度两只移调器送回混响。朴素地再加读头不该再试。移调器仍会按窗口周期抖动，换算法要等听完现有尾巴并明确要改 |
| 声部 3/6 应改成指数斜坡 | 三角波是标明的临时模型。听哪一个电路节点还没有证据。只能先听现状，不能当成做错了 |
| drone 音量包络改成指数 | 经典声部和声部 3/6 故意共用直线升降（`ar_envelope.h`），避免同一块面板两套时间手感。可演奏振荡器的指数包络是另一块面板。只有长音涨落听起来像推子时，才渲染一段来比 |
| 五只发生器各自固定偏一点声像 | 和“只做硬件有的东西”冲突。五只先加总，再进混音器一路，声像做在混音器上 |
| 给 VCO 加慢漂移 | 不在行动清单里。VCO 要求相同输入逐比特一致（`vco.h`）。要加漂移就得同时改这个约定 |

审查初稿的价值因此是一张选项清单，不是一张缺陷清单。抗混叠不必再加码，也不必换合成法家族。这个判断保留。

## 6. 可以重做的听感操作

操作约定和 `design/MANUAL_TESTS.md` 相同。旋钮拖动，双击回到默认。拔线：按住线的**输入端**插孔往外拖。RESET PANEL 在键盘菜单里，4 秒内点两次。VCO A 最下排从左到右是 **1v/oct**、**cv**、**pwm**、**sync**，**cv** 是左边第二个孔。**lin / exp** 拨在上面是线性。波形图标：大约 10:30 三角，11:30 锯齿，12:30 方波。混音器顺序：DRONE 1、2、3、EXT.AUDIO、VCO A、VCO B、PREAMP、DRONE 4、5、6。

第一次用摇杆时如果完全没变化，先确认听到的是 VCO A：drone 全关、混音器只留 VCO A、envelope A 的 **hold** 点亮。**cv amt** 在最左边，或线插在第三个孔 **pwm** 上而 **pwm** 旋钮在最小，摇杆也没有任何作用。插到 **1v/oct** 则一推音高就会掉。

### 6.1 摇杆：线性调频向左的静音区

1. RESET PANEL。BLEND 拧到最左。DRONE VOICES 六个都关掉。VOICE MIXER 只留 **VCO A**。点亮 envelope A 的 **hold**，先确认有一个持续的音。
2. **lin / exp** 拨在上面。**cv amt** 拧到最右。双击摇杆，再双击 **OFFSET X**，都回到正中。
3. 接线：JOYSTICK 的 **X OUT** → VCO A 的 **cv**。正中时音高应和没接线时一样。
4. 向左慢慢推，停三次。刚离开正中：音高变低，音还在，这段大约只占向左全程的五分之一。音正好消失的位置是 −1 V，振荡器停了，不是变得极低。从这里推到最左：声音保持没有。向左剩下的大约五分之四都是空的。
5. 从最左推回正中：过了消失点，音才从很低的地方回来。向右推到底：音高一路升高变尖，没有静音。

2026-10-08 业主听过，和上述一致。过零调频要填上的就是向左那一段静音。现在它是空的。

### 6.2 VCO A 的方波调制 VCO B

先拔掉 6.1 的线（从 VCO A 的 **cv** 往外拖）。不插线时，VCO A 的波形自己进 VCO B 的 **cv**。混音器里把 VCO A 关小，不会停掉这条调制。

1. RESET PANEL。BLEND 最左。DRONE VOICES 全关。VOICE MIXER 只留 **VCO B**。点亮 envelope B 的 **hold**。应是一个持续、干净的音。
2. VCO B 的 **lin / exp** 在上面，**cv amt** 先拧到最左。
3. VCO A 的 **oct** 留在 **low**，**tune** 拧到最左，大旋钮对准方波（大约 12:30）。
4. 把 VCO B 的 **cv amt** 慢慢拧到最右。声音从干净变得发劈、发紧。方波每秒变两百来次，听成一种粗糙音色，不是摇杆那种“推过去就一直没声”。
5. 把 **cv amt** 往回拧，停在仍然连续、刚刚开始发粗的位置。
6. 大旋钮转回正中（正弦），**cv amt** 再开满：粗糙轻很多。转回方波，发劈回来。若几乎听不出差别，把 FILTER 两个 **FREQ** 拧到最右再听。

2026-10-08 业主听过，和上述一致。开满时的发劈若能用，或演奏时本来就会停在还连续的位置，就不必改。只有想把调制再推深、并且深了以后仍然要有音，过零才有理由。那要改 `ARCHITECTURE.md` 4.3，不是补漏洞。

### 6.3 声部 3 的三角波，对照锯齿和方波

1. RESET PANEL。BLEND 最左。FILTER 两个 **FREQ** 拧到最右。
2. DRONE VOICES 只开 **3**。VOICE MIXER 只把 **DRONE 3** 开到一半以上。**fm**、**am** 关掉。**NOISE** 拧到最小（默认在中间，不拧会混进嘶声）。**PITCH** 放在一个舒服的中音。
3. 应是柔、空、几乎不发嗡的音，接近笛声。
4. 关掉声部 3，混音器改只听 **VCO A**，点亮 envelope A 的 **hold**，**oct** 留在 **low**。
5. 大旋钮大约 10:30（三角）：和声部 3 同一类，柔、空。大约 11:30（锯齿）：变亮，发嗡、发毛。大约 12:30（方波）：又变空，但更硬，带鼻音。
6. 回到只听 DRONE 3。它和三角波对得上，不是锯齿，也不是方波。
7. 可选：点亮声部 3 的 **fm**，**rate** 放慢。音高在两个音之间跳。跳的是方波调制，音调本身仍是那个空的三角波。听完关掉 **fm**。

2026-10-08 业主听过，和上述一致，并认为声部 3 现在这个声音可以接受。指数斜坡不在面板上，这次不能判断换过去会不会更好。以后若觉得它比四个经典声部空、闷，再考虑指数斜坡或改听方波。那是标明的临时模型，不是纠错。

### 6.4 白噪声，以及 96 kHz 时嘶声变轻

1. RESET PANEL。BLEND 最左。DRONE VOICES 只开 **3**。VOICE MIXER 里 **DRONE 3** 开到一半以上。
2. **PITCH** 拧到最小（音调关掉）。**fm**、**am** 关。**NOISE** 拧到最大。FILTER 两个 **FREQ** 拧到最右。
3. 应是稳定的、很亮的嘶声，像收音机没调到台，没有音高。这就是白噪声。
4. 两个 **FREQ** 一起往左：高音被削掉，变成更闷的风声。这是滤波器在削同一路白噪声，不是另一种噪声。拧回最右，亮嘶声回来。
5. 记住 **MASTER** 的位置。菜单栏 Lunar 24 → Preferences…，Sample Rate 改成设备里有的 **96000**。没有 96000 就停。切换时会短促响一下，面板不用重调。和刚才比，嘶声应稍微轻一点。听完把采样率改回去。

2026-10-08 业主在 96000 上听过，嘶声确实轻轻变弱。平时固定一个采样率就听不出来。只有经常在 44.1 和 96 之间换、而且觉得嘶声忽大忽小，才值得让可听噪声的响度不再跟着采样率走，同时保持这种亮嘶声。改成粉红噪声是另一种音色。

## 7. 到 2026-10-08 为止的结论

三处都不是故障。要改，只能是因为演奏时想要另一种声音，并且接受改写已经记下的决定。

| 听过的现象 | 现在的决定 |
|---|---|
| 摇杆向左约五分之一后 VCO 停住；向右一直变尖 | 线性调频的既定行为。过零只在“深的负向调制仍然要有音”时才做，并改 `ARCHITECTURE.md` 4.3 |
| VCO A 方波、VCO B 的 **cv amt** 开满时发劈；拧回来就重新连续；正弦温和得多 | 同上。默认接线已经是 A 进 B、开满、线性。方波和锯齿开满会发劈 |
| 声部 3 单独响时空而柔，和三角波一致 | 今天接受。指数斜坡或改听方波留到以后真的觉得太闷再试 |
| **NOISE** 是亮嘶声；96000 时轻轻变弱 | 今天不改。固定一个采样率没有演奏问题。粉红噪声不拿来修这个响度差 |
| 经典声部 **VOLT** 过半变粗 | 没有单独再听。深度上限 0.9，正常操作不停振。不是过零的例子 |

明确先不做：给闪光混响再加读头；五只发生器拆开声像；把 drone 直线包络改成指数；给 VCO 加漂移；把过零当成 VCO 的缺陷去补。抗混叠和滤波器拓扑不再加码，除非深调频或同步扫频时能听到哨音。

## 8. 以后调音时怎么用这份记录

先照第 6 节把相关的一段再听一遍，确认不满的是哪一种声音。然后只改那一处，用 `lunar24_render` 导出和上一版对比，听完再留。不要为了“还有更高级的算法”同时改过零、波形和噪声。
